# Ideas to brainstorm

Running list of ideas not yet brainstormed into a design. Once an idea is
brainstormed, move it out of this list (the resulting spec under
`docs/superpowers/specs/` is the record from then on).

- **Make all fields language-aware.** Raised 2026-08-20. Needs scoping
  before brainstorming: could mean per-field *values* stored/shown in
  multiple languages (e.g. a Category value entered once but displayed
  differently per active UI language), or the field *names/labels*
  themselves (built-in and custom) being translatable rather than fixed
  strings — these are different designs with different scope. Pin down
  which one (or both) is meant before starting the brainstorm.
